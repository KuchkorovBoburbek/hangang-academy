# Grammatika qo‘llanmasi manbalari

- `content.py` — 111 grammatik bandning koreyscha shakllari, o‘zbekcha izohlari va misollari.
- `build_handbook.py` — dastlabki PDF generatorining nusxasi. Undagi `ROOT`, `FONT` va `LOGO` manzillari dastlabki macOS ish muhitiga tegishli; boshqa kompyuterda ularni mahalliy loyiha, shrift va logo manzillariga moslash kerak. Python va ReportLab hamda koreyscha belgilarni qo‘llaydigan TTF shrift kerak.
- Tayyor PDF: [HangangAcademy grammatika qo‘llanmasi](../output/pdf/HangangAcademy_TOPIK_II_Grammatika_1-4.pdf).

Veb-ilova tayyor JSON kontentdan foydalanadi. Ilovani ishga tushirish uchun PDF generatorini qayta ishga tushirish shart emas.
